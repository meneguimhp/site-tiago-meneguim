# SDD — Site Pessoal (Execução Técnica)

## 1. Objetivo

Construir um site profissional com foco em:

* Autoridade técnica
* Geração de oportunidades (mentoria / consultoria)
* Execução rápida (MVP)

Domínio:

```
tiagomeneguim.com.br
```

---

## 2. Stack Técnica

* React + Vite
* TypeScript
* CSS (inicial simples, evoluir para Tailwind depois)
* Deploy: Cloudflare Pages
* Repo: GitHub

---

 ├── pages/
 ├── App.tsx
