# Site Tiago Meneguim

MVP do site pessoal de Tiago Meneguim, baseado no SDD do projeto.

## Stack

- React + Vite
- TypeScript
- CSS simples
- Deploy previsto: Cloudflare Pages

## Como rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy no Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`
- Domínio planejado: `tiagomeneguim.com.br`
